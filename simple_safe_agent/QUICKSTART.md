# Quick Start Guide

## Two Commands to Run

### 1. Export your OpenAI API key
```bash
export OPENAI_API_KEY=sk-your-actual-key-here
```

### 2. Start with Docker Compose
```bash
docker-compose up --build
```

## Test It

```bash
# Run all tests
docker-compose run --rm test
```

## Stop It

```bash
docker-compose down
```

That's it!
